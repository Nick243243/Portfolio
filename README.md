# Tris - Python

## Introduction

This project was developed during the **second week of my internship**, when I was still at an early stage of my programming journey.

It was one of my first projects developed in Python and was created as a practical exercise to apply the programming concepts I had learned up to that point. 
Although the project is relatively simple, it represents an important step in my early experience with Python and software development.

The project consists of a terminal-based Tic-Tac-Toe game for two players, with keyboard controls and automatic detection of wins and draws.

## Features

* Two-player game
* Player 1 uses `X`
* Player 2 uses `O`
* Keyboard navigation with WASD or arrow keys
* Automatic win detection
* Automatic draw detection
* Option to start a new game
* Terminal-based interface

## Requirements

* Python 3.x
* Windows

The project uses only Python Standard Library modules:

* `os`
* `msvcrt`
* `time`

No external packages are required.

## How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/tris-python.git
```

Navigate to the project directory:

```bash
cd tris-python
```

Run the program:

```bash
python main.py
```

## Controls

| Key                 | Action      |
| ------------------- | ----------- |
| `W` / `Up Arrow`    | Move up     |
| `A` / `Left Arrow`  | Move left   |
| `S` / `Down Arrow`  | Move down   |
| `D` / `Right Arrow` | Move right  |
| `Space`             | Select cell |
